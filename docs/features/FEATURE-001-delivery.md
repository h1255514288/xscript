## 用户验收步骤

1. 保持 XScript 无障碍和截图权限开启，在手机打开目标页面。
2. 打开工作台，获取节点；拖动分隔线、缩放截图，确认选点准确；悬停预览不改变条件，父级路径能切换节点。
3. 选中有文字的节点，将文字改为正则，例如 `.*目标文字.*`，再次获取后条件仍保留；在线测试确认数量、耗时和高亮。
4. 点击结果列表定位树行；取消“只看本次匹配结果”查看全树；复制代码，检查条件与界面一致。
5. 输入非法正则测试，再点“重置测试”；确认错误、高亮消失，条件恢复。
6. 从 IDE 的“节点”按钮打开页面，选取节点后“插入到 IDE”，确认代码插入原 Python 文件并保留缩进；此步骤在安装新版 APK 或允许编辑的正常设备页面上验收保存行为。
7. 如遇连接中断，确认旧树和条件保留并提示重新获取；恢复连接后再次获取可测试。等待查询时可停止等待，条件不变。

## 已知边界

- 未验证 Root；XScript 没有 AScript HID 节点通道，不能称为其全部设备能力的一比一复制。条件分组、自定义排序已经实现。
- XPath 查找可与链式关系组合；相关关系从 XPath 命中节点继续计算。树与截图并非原子快照，界面发生变化时应重新获取。
- 在线测试最多展示 50 个结果；结果截断时显示上限提示。
- 停止等待只取消浏览器请求，不保证终止设备查询；测试截图未刷新时不绘制结果框。断连、超时与截图失败由本地服务和浏览器模拟验证，未主动断开手机网络。
- 本地预览不转发项目保存/运行/删除；正式使用设备自带页面需要将这些前端资源打包进入新的 APK。
- 实际设备点击/长按、用户业务验收、新 APK 的安装验收及公开发布尚未执行。

回退本功能只需恢复前端文件与入口并重新构建对应 APK；没有数据库或公共协议迁移。源码预览可直接 Ctrl+C 停止。
