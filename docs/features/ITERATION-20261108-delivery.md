## 限制与后续条件

HID 按用户决定待硬件接入。真实 OSS 账户、跨主机 SDK 构建、系统 APK 安装器确认流程、设备断电 / 存储耗尽 / 主动断网及 Root 通道未验证；对应模拟或主机测试不能写成设备通过。三项模型文件测试仍需实际模型集。用户业务验收待反馈。

16 KB 检查在兼容模式通过，46 个 Python 依赖库仍为 4 KB 对齐，未在 16 KB 设备实测；保护字节码可被反编译，不承诺加密。

同包名覆盖安装必须签名相同；本轮先备份原 APK、核对签名，再保留数据安装，未卸载用户应用。测试结束后仅卸载本轮创建的隔离验收 App、停止临时后台并移除它的端口转发；用户原有项目列表、设置、配对偏好、无障碍 / 截图及通知访问权限已核对保留，保留节点工作台转发入口。公开发布、签名迁移和 HID 接入分别按条件推进。
