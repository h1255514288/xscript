# FEATURE-001：独立节点工作台

状态：待用户验收。分支：`feat/webide-node-selector`。基于 XScript v0.6.0，已生成本地 debug 验收 APK，尚未公开发布。

## 需求与范围

用户负责需求和验收，开发负责实现与验证。目标是修复 Web IDE 节点树体验：获取设备节点、生成代码、支持正则匹配、在线测试、快速复制和重置。后续明确要求独立页面，并提供 AScript 节点树截图及可访问页面作为交互参考。

页面采用截图、节点树、属性与选择器三栏布局，占用完整页面，支持列宽调整、字号和主题。IDE 通过新标签页打开工作台；通过同源、来源窗口和会话标识校验的消息将生成代码插回原 IDE，原编辑内容保留。

本期包括字段条件、XPath、父/子/兄弟关系、查找一个/全部、点击/长按代码生成、只读在线测试、结果树筛选、截图高亮、复制和重置。采用现有 `/ui-tree`、`/screen`、`/eval` 协议；运行时修复 XPath 命中后继续应用关系和过滤的语义，不新增公共 Python API 或数据库结构。

本轮按用户选择继续优化布局、定位和测试反馈：截图适应/缩放与悬停预览、父级路径与结果定位、刷新保留手动条件、断连保留旧快照、请求超时与停止等待，以及窄屏操作区可点击性。

## 实现边界

- 自动条件与可编辑条件共享生成器；测试与复制/插入使用同一套条件。
- 正则语义来自 XScript 的 Python 运行时，测试时预编译以显示非法表达式错误。
- 测试最多显示 50 个匹配；生成“查找全部”的代码调用运行时 `find_all`。
- 更换选择、编辑条件、刷新、重置后使旧结果作废；获取树的截图不得清除较新的测试结果。
- 刷新成功且找到原控件时保留手动条件；刷新失败保留旧快照并暂停测试。测试截图失败时保留结果列表，不在旧图绘制新结果。
- 设备请求有明确超时；停止等待取消浏览器请求，不能保证终止设备查询。截图标明来源和获取时间，避免混用不同快照的选点。
- 只读测试与执行动作分开。设备实际点击/长按没有作为自动验收操作执行。
- 保留原有稳定定位、最近选择和键盘操作。原编辑器权限引导测试迁移到独立测试文件。
- 条件支持分组、自定义拖拽/键盘排序并保存偏好。AScript HID 等通道差异，以及 XPath 关系限制，见 [使用说明](../NODE_WORKBENCH.md)。

## 验收标准

1. 从 IDE 打开独立工作台，原脚本和未保存内容保留；直接 URL 也能进入。
2. 获取真实设备树和截图，点选任一节点能够显示属性并生成代码。
3. 精确、包含、正则混用后，复制代码与在线查询的条件一致；非法表达式有明确错误。
4. 完整树、搜索、折叠、系统栏过滤、关系、XPath 和全部查找可用。
5. 测试显示数量、结果列表、树中命中项和截图框；重置恢复默认并清空结果，旧响应不回填。
6. 从 IDE 打开的页能插回 Python 文件，补齐 import、保持缩进；外部窗口消息不能插入。
7. 无权限、无截图、空条件和设备错误有可恢复提示；窄屏无横向溢出，操作按钮不被状态栏遮挡。
8. 缩放后截图选点准确；悬停不改变条件；父级路径可选取，结果定位能清除挡住目标的搜索。
9. 刷新保留手动正则、XPath 和关系；断连保留旧树与条件，重连后可测试；停止等待后迟到结果不覆盖当前状态。

实际证据与限制见 [交付记录](FEATURE-001-delivery.md)。
